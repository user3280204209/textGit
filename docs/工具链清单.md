# 工具链清单：必须 / 可选 / 加分项

> 面向全组。**先看"必须层"，装完就能跑项目**；其余按你负责的模块再装。
>
> 组员多、基础不一，最容易出的问题不是技术难，而是**每个人装的东西不一样**。
> 所以本清单把边界划死：必须层人人一致，可选层按角色认领。

## 零、一句话结论

**必须先装（缺一个项目就跑不起来）：**

| 类别 | 清单 |
|---|---|

## 一、必须层（全组每人，逐项核对）

| 软件 | 版本要求 | 当前状态（技术负责人机器） | 获取方式 |
|---|---|---|---|
| **Python** | **3.13.x** | ✅ 3.13.12（随 Miniconda） | 由 Miniconda 提供，不单独装 |
| **Miniconda** | 最新 | ✅ `D:\LangChain\Miniconda` | https://docs.conda.io/en/latest/miniconda.html |

## 二、可选层（按角色认领，不要全装）

### 2.1 按功能模块划分

| 你负责的功能 | 需要额外安装 | 说明 |
|---|---|---|
| 前端界面 | 无（已在必须层） | React/Vite/pnpm 都属必须层 |
| 画像构建 | 无 | 纯 LLM 调用 |
| 讲解文档生成 | 无（`python-docx` 已在主依赖） | — |
| 思维导图 | 无 | 输出 Mermaid，**前端渲染**，不需要 Graphviz |
| 练习题生成 | 无 | 纯 LLM |
| 拓展阅读 | 无 | 纯 LLM |
| **视频/动画生成** | 见下方 2.2 | 三选一 |
| 代码实操案例 | 无 | 纯 LLM |
| 学习路径规划 | 无 | 纯 LLM |
| 精准资源推送 | 远程 Embedding API（无需装包） | 见 2.3 |

**结论：6 类资源里有 5 类不需要任何额外安装。** 这是刻意设计的 ——
降低全组环境复杂度。

### 2.2 视频/动画生成：三条路线，选一条

| 路线 | 需要装 | 优点 | 缺点 |
|---|---|---|---|
| **C1 远程视频 API**（推荐） | 无需装包，只需 API Key | 零环境成本，出片快 | 要花钱，效果不可控 |
| **C2 Manim 本地渲染** | `manim` + **系统级 FFmpeg** | 完全可控，效果专业 | FFmpeg 安装易踩坑，渲染慢 |
| **C3 HTML5 动画 + 录屏** | `playwright` | 免费，可控 | 需要写前端动画，工作量大 |

> **建议**：先用 **C1 的思路**做演示（脚本 + API 出图），
> 同时用 HTML5 动画兜底。这样即使 API 不可用，答辩现场也有能播的东西。

> 📌 注意：当前代码里 `VideoAnimationAgent` 在**未配置多模态 API 时自动降级**
> 为"脚本 + 动画方案"，状态标记为 `degraded`。这是有意为之 ——
> **宁可如实降级，也不要让答辩现场卡住。**

### 2.3 向量检索 / 精准推送

**不要装 `faiss` / `chromadb` / `sentence-transformers`。**

改用：**远程 Embedding API + 余弦相似度**
```powershell
# 只需 numpy（轻量，有 3.13 wheel）
pip install numpy
```
向量存进 SQLite 或直接内存里算余弦相似度。
几十到几千条资源规模下，这比向量数据库更快更简单。

### 2.4 部署相关（答辩前才需要）

| 工具 | 何时需要 |
|---|---|
| **Docker Desktop** | 要打包成容器部署到服务器时 |
| **PostgreSQL** | 替换 SQLite 做正式部署时（改一处 `DATABASE_URL`） |
| **Nginx** | 前端静态资源 + 反向代理 |
| 云服务器 | 老师要求"部署到服务器"时 |

> 本机开发**完全不需要** Docker 和 PostgreSQL。SQLite 足够。

## 三、明确不要装的（重要）

| 不要装 | 原因 |
|---|---|
| `torch` / `pytorch` | Windows + Python 3.13 **缺少预编译 wheel**，安装需现场编译，极易失败；且本方案全部走 API，用不到 |
| `sentence-transformers` | 依赖 torch，同上 |
| `faiss-cpu` / `faiss-gpu` | 3.13 支持滞后，且不需要本地向量库 |
| `transformers`（本地推理） | 体积数 GB，且本地小模型扛不住多智能体推理 |
| `ollama` + 本地大模型 | 7B 模型做多智能体复杂推理效果差，会拖垮演示效果 |
| `Graphviz`（系统级） | 思维导图改用 Mermaid，前端直接渲染，无需系统依赖 |

> **如果你已经装了上述任何一个**：不影响项目，但**不要写进 `requirements.txt`**，
> 也不要让其他组员装。否则有人装不上就卡住了。

## 四、可选效率工具（个人选择，不写进项目要求）

| 工具 | 作用 | 是否影响项目 |
|---|---|---|
| **Claude Code** | AI 辅助写代码，能帮你读代码、写测试 | ❌ 不影响。项目本身不依赖它 |
| **Codex / 其它 AI 编程工具** | 同上 | ❌ |
| **PyCharm 专业版** | 替代 VS Code，Python 调试更强 | ❌ 用哪个编辑器都行 |
| **Postman / Apifox** | 调接口 | ❌ 用 `/docs` 就够了 |
| **Docker** | 环境隔离 | ⚠️ 部署时才需要 |
| **Windows Terminal** | 更好的终端体验 | ❌ |

> **关于 Claude Code**：它装在 Node.js 之上，用它之前要先装 Node。
> 它能显著加速开发，但**不是项目依赖** —— 谁不装都能正常参与开发。

## 五、环境自检

装完后**不要靠猜**，直接问后端：

```powershell
# 启动后端后访问
curl http://127.0.0.1:8000/api/env-check
```

或浏览器打开 http://127.0.0.1:8000/api/env-check

返回里每一项都会告诉你**是否通过 + 怎么修**，例如：

```json
{
  "item": "LLM API Key",
  "ok": false,
  "hint": "在 backend/.env 填 LLM_API_KEY"
}
```
